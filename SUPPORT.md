# Support

## Questions and usage help
Use GitHub Discussions when available, or open an issue using the most relevant template.

## Bug reports
Please include:
- app/package version
- vehicle preset or custom inputs
- analysis conditions
- expected behavior
- observed behavior
- minimal reproducible steps

## Engineering-model questions
When questioning a result, include units and the assumptions used. Screenshots are useful, but numeric inputs are preferred for reproducibility.

## Scope
This project provides engineering estimates and educational/research tooling. It is not a certification, homologation or safety-decision tool.
