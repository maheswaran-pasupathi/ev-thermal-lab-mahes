# Security Policy

## Supported versions
Security fixes are applied to the latest released version.

## Reporting
Please do not publish API keys, credentials, private vehicle data, personal data or security-sensitive details in a public issue.

For a security-sensitive problem, contact the maintainer privately through the contact information on the maintainer's GitHub profile.

## Secrets
The application is designed so external-service credentials can be supplied through deployment secrets or environment variables. Secrets must never be committed to the repository.
